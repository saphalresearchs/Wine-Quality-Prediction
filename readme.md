# 🍷 Wine Prediction System

## 📌 Overview
The **Wine Prediction System** is a machine learning project that classifies different types of wine based on their chemical properties. After testing multiple models, the **Random Forest Classifier** demonstrated the best accuracy on the test dataset, making it the final choice for prediction.

## 🚀 Features
- Predicts the quality/class of wine based on given chemical features
- Uses a **Random Forest Classifier** for high accuracy
- User-friendly interface (if applicable, e.g., Streamlit, Flask, etc.)
- Efficient and scalable model

## 🛠️ Technologies Used
- **Python**
- **Scikit-Learn** (for model training and evaluation)
- **Pandas & NumPy** (for data manipulation)
- **Matplotlib & Seaborn** (for data visualization)
- **Jupyter Notebook** / Any IDE for model development

## 📂 Dataset
- The dataset used contains multiple physicochemical properties of wine samples.
- Features include **fixed acidity, volatile acidity, citric acid, residual sugar, chlorides, free sulfur dioxide, total sulfur dioxide, density, pH, sulphates, and alcohol.**
